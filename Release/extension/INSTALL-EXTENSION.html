Downloader-extentie laden

Chrome en Edge laten extenties niet stilzwijgend installeren. Dit is eenmalig en duurt ~20 seconden.

  1. Open de extentiepagina in je browser (chrome://extensions of edge://extensions).
  2. Zet rechtsboven Developer mode / Ontwikkelaarsmodus aan.
  3. Klik Load unpacked / Uitgepakte extensie laden.
  4. Kies deze map:
    EXTENSION_PATH

Daarna verschijnt het Downloader-icoon in de werkbalk. Native messaging is al door de installer geregistreerd.

Later: in de Chrome Web Store / Edge Add-ons is deze stap niet meer nodig.

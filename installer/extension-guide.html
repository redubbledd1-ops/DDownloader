Downloader-extentie laden (v1.1)

Chrome, Edge en Firefox (Windows) gebruiken dezelfde map. Browsers laten extenties niet stilzwijgend installeren — dit is eenmalig (~20 seconden).

Chrome / Edge

  1. Open chrome://extensions of edge://extensions.
  2. Zet Ontwikkelaarsmodus / Developer mode aan.
  3. Klik Uitgepakte extensie laden / Load unpacked.
  4. Kies deze map:
    EXTENSION_PATH

Firefox (Windows)

  1. Open about:debugging#/runtime/this-firefox.
  2. Klik Tijdelijke add-on laden / Load Temporary Add-on.
  3. Kies manifest.json in dezelfde map als hierboven.

Tijdelijke Firefox-add-ons verdwijnen na een herstart. Native messaging registreert de installer als je Firefox hebt aangevinkt.

Firefox voor Android

Installeer de Downloader-APK. Laad de Android-variant vanaf de pc met:

scripts\run-firefox-android.ps1

Op Android opent Naar App de Downloader-app (geen native messaging in de browser).

Downloader-extentie laden

Chrome, Edge en Firefox gebruiken dezelfde map. Browsers laten extenties niet stilzwijgend installeren — dit is eenmalig (~20 seconden).

Chrome / Edge

  1. Open de extentiepagina (chrome://extensions of edge://extensions).
  2. Zet rechtsboven Developer mode / Ontwikkelaarsmodus aan.
  3. Klik Load unpacked / Uitgepakte extensie laden.
  4. Kies deze map:
    EXTENSION_PATH

Firefox (desktop)

  1. Open about:debugging#/runtime/this-firefox.
  2. Klik Load Temporary Add-on / Tijdelijke add-on laden.
  3. Kies manifest.json in dezelfde map als hierboven.

Tijdelijke Firefox-add-ons verdwijnen na een herstart. Voor een permanente installatie: Firefox Developer Edition, of later een ondertekende .xpi.

Firefox voor Android

Installeer eerst de Downloader-app (APK). Daarna dezelfde extentie-map laden via debug (desktop about:debugging → je telefoon) of “add-on vanuit bestand”. Op Android opent de knop Naar App de Downloader-app (geen native messaging).

Daarna verschijnt het Downloader-icoon in de werkbalk. Native messaging is al door de installer geregistreerd voor desktop-browsers.
